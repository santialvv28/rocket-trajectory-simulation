# ROCKET TRAJECTORY SIMULATION

A MATLAB simulation of 2-D rocket projectile motion using basic kinematics.

## Features
- Calculates flight time
- Calculates maximum height
- Calculates horizontal range
- Plots rocket trajectory

## Inputs
- Initial velocity
- Launch angle
- Initial height
- Gravitational acceleration

## Tools
- MATLAB
- Projectile motion equations
